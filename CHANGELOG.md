# Changelog

## 0.1.0 — 2026-08-21

- Added canonical content-addressed storage, fixed-size chunking, SHA-256 verification, and deduplication.
- Added permission-aware copy-on-write files/directories, metadata, history, atomic journaled commits, and recovery.
- Added snapshots, diff/restore, reachability indexes, analytics, and mark-and-sweep garbage collection.
- Added management CLI, authenticated REST API with OpenAPI/audit logs, and optional Linux FUSE mounting.
- Added compatibility fixtures, hostile-input limits, verified backups, randomized stress tests, pinned release builds, CI, threat model, and operations documentation.
