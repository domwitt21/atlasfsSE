# Code of conduct

AtlasFS contributors are expected to maintain a welcoming, professional, and
technically constructive community.

## Expected behavior

- Be respectful, patient, and considerate.
- Critique ideas and code rather than people.
- Welcome questions and differing experience levels.
- Give credit and accept responsibility for mistakes.
- Protect private information and follow coordinated vulnerability disclosure.

Harassment, discrimination, threats, sexualized attention, personal attacks,
doxxing, and sustained disruption are not acceptable in project spaces.

Report conduct concerns privately to the repository owner through their GitHub
profile. Reports will be reviewed confidentially and handled proportionately,
which may include a warning, content removal, temporary restriction, or a ban.
Good-faith reporters will not face retaliation.

This policy applies to repository discussions, issues, pull requests, reviews,
and other spaces where someone represents the AtlasFS project.
